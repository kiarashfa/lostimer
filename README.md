# LOSTimer

**LOST + timer**  is a functional countdown timer for everyday use. Set any duration via the ⚙ icon, type `4 8 15 16 23 42` to reset, or use terminal commands (`home`, `communication`, `instructions`, `orientation`, `faq`) to navigate the monitor screen. 

This is a fan tribute to ABC's LOST (2004–2010), simulates the countdown terminal from The Swan Station (aka the Hatch), complete with a flip-clock timer, CRT monitor interface, Apple II keyboard, and the full failure sequence if you don't push the button in time.

Namaste. And good luck!
